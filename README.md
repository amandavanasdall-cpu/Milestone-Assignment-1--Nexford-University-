# Milestone-Assignment-1--Nexford-University-
Milestone Assignment 1: Policy Management System for an Insurance Company
This project will allow policy managers to manage policyholders, products, and payments. It allows policy managers to add and suspend policyholders, register new members, and manage current policy products. 
The assignment involved the following tasks: class creation, policyholder management, payment management, product management, and policyholder demonstrations. 
Python was used to create this project. 

To run the program, the file named main is used to run the other listed files (policyholder, products, and payment). All files are .py, and ensuring all .py files are in the same folder allows the program to run. 

After downloading all files and opening main in the same folder. The main file will import classes from the other files and create products, policyholders, and payment information. The results will be displayed in the terminal. 

The two policy products listed are pet insurance and home insurance, but edits can be made to change policy names, information, or to add multiple products if needed.
